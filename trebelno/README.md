| PDF | Para quién | Qué tiene |
|---|---|---|
| `pdf/Trebelno_Cuestionario_Comercial.pdf` | Cliente | 15 preguntas (paleta rojo/bordó del salón) |
| `pdf/Trebelno_00_Estrategia_y_Campana.pdf` | Jona · cliente | Test 1, competencia, estructura con USD 20/día, reglas, WhatsApp, calendario |

Los creativos se editan en `src/datos.py`; los datos del cliente van como `[[VARIABLE]]` y salen en amarillo.

```
cd src && python3 build.py && python3 cuestionario.py && node imprimir.js
```
